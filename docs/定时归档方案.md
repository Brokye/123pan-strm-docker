# 云盘文件夹定时归档方案(扫描→STRM→删除)

> 需求:定时把云盘指定文件夹的所有文件(递归)生成 STRM 保存到秒传库,然后删除云盘中的文件。
> 状态:方案待确认(默认采用推荐项,标注"可调"处可改)

---

## 1. 现状复用(零重写)

| 步骤 | 复用现有函数 | 位置 |
|---|---|---|
| 递归扫描云盘文件夹(分页+递归) | `Pan123.listFilesSingle` | internal/app/pan123.go |
| 生成秒传 JSON(含进度) | `panExportTask` 的生成逻辑 | internal/app/strm.go |
| 保存为库 JSON | `Config.NormalizeLibrary` + `writeLibraryFile` | internal/app/config.go |
| 生成 STRM(分类目录/进度/字幕) | `generateStrmTask` | internal/app/strm.go |
| 删除云盘文件(移回收站/彻底) | `Pan123.deleteFile` | internal/app/pan123.go |

新增代码只做:**任务配置管理 + 定时调度 + 流水线编排**,预计 ~300 行 Go + ~150 行前端。

## 2. 流水线(带安全闸门)

```text
定时触发(容器内 cron / 手动 API)
  ↓
递归扫描目标文件夹(listFilesSingle,收集文件+文件夹 FileId)
  ↓ 文件数为 0 → 跳过,记"空"历史
生成秒传 JSON → normalize → 保存为库 libraries/*.json
  ↓
生成 STRM 到输出目录(复用 generateStrmTask)
  ↓
[安全闸门] 视频 STRM 成功数 == 扫描视频数?
   ├─ 是 → 删除成功生成项的云盘文件(回收站优先)→ 文件夹清空后删文件夹
   └─ 否 → 整批中止,云盘文件原样保留,记录失败清单
  ↓
写运行历史 jobs/history/*.json + 容器日志
```

删除粒度:按文件维度——**只有 STRM 生成成功的文件才删其云盘文件**,失败项保留,下次运行重试。

## 3. 任务配置(jobs/*.json,每任务一文件)

```json
{
  "id": "archive-movies",
  "name": "电影归档",
  "enabled": true,
  "cron": "0 3 * * *",
  "pan_folder_id": 123456,
  "pan_folder_name": "电影",
  "category": "电影",
  "output_dir": "/strm",
  "include_subtitles": true,
  "delete_after": true,
  "delete_mode": "trash"
}
```

| 字段 | 说明 |
|---|---|
| `cron` | 标准 5 段 cron(容器内 robfig/cron 调度)**[默认:容器内定时器,可调]** |
| `delete_mode` | `trash`(移回收站,默认)/ `permanent`(彻底删除)**[可调]** |
| `enabled` | false 时只保留配置不调度 |

## 5. 安全设计(核心)

1. **安全闸门**:视频 STRM 生成数不齐 → 不删任何文件
2. **按文件删除**:只删已成功生成 STRM/字幕的文件,失败项保留
3. **回收站优先**:默认 `trash`,误删可恢复;`permanent` 需在任务配置里显式开启
4. **自动备份**:删除前备份库 JSON(`*.bak.<ts>`)
5. **幂等**:文件夹已空 → 跳过;同一任务运行中禁止并发(任务锁)
6. **试跑**:手动 `run` 端点先验证一轮,确认无误再开 `enabled`
